# Tajweed Trainer

A free, browser-based Quran recitation practice tool with Al-Azhar Mushaf color-coded Tajweed rules.

## Features

- 📖 **Al-Azhar 8-Color System** - Official Tajweed Mushaf color coding
- 🎧 **Listen to Reciters** - Yasser Al-Dosari, Mishary Alafasy, Al-Husary, Al-Minshawi
- 🎙️ **Record Yourself** - Practice and compare your recitation
- ✅ **Self-Assessment Checklist** - Rule-by-rule verification
- 📱 **Mobile Friendly** - Works on phones and tablets

## Color Legend

| Color | Arabic | Rule | Description |
|-------|--------|------|-------------|
| 🔴 Dark Red | مد لازم | Madd Lazim | 6 counts |
| 🔴 Blood Red | مد واجب | Madd Wajib | 5 counts |
| 🔴 Orange Red | مد جائز | Madd Jaiz | 2/4/6 counts |
| 🔴 Cumin Red | مد طبيعي | Madd Tabee'i | 2 counts |
| 🟢 Green | غنة | Ghunnah | Nasalization |
| ⚫ Gray | ما لا يلفظ | Silent | Not pronounced |
| 🔵 Blue | قلقلة | Qalqalah | Echo on ق ط ب ج د |
| 🔵 Dark Blue | تفخيم | Tafkheem | Heavy letters |

## Usage

1. Select Surah and Ayah range
2. Click "Load Tajweed Rules"
3. Listen to reference recitation
4. Record yourself
5. Use checklist to self-assess
